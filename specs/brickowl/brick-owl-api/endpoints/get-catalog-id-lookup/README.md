# GET /catalog/id_lookup

Lookup BOIDs by external ID

Retrieve possible BOIDs for another identifier such as a set number or design ID.

## Parameters

- **key** (string) *required* — Brick Owl API key.
- **id** (string) *required* — Identifier to look up.
- **type** (string) *required* — Item type filter.
- **id_type** (string) — Optional ID type filter.

null
