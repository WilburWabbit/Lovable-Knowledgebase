# GET /affiliate/lots

List affiliate store lots

Retrieve the lots for a store that has opted in to your affiliate scheme.

## Parameters

- **key** (string) *required* — Brick Owl API key.
- **store_id** (integer) *required* — The store's unique ID.
- **type** (string) — Optional item type filter.
