# GET /catalog/search

Search catalog

Search, browse, and filter the catalog. Use the query term 'All' to browse.

## Parameters

- **key** (string) *required* — Brick Owl API key.
- **query** (string) *required* — Search term. Use 'All' to browse.
- **page** (integer) — Optional page number.

```
null
```
