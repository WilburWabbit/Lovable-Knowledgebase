# GET /catalog/list

List catalog items

Get a list of all items in the Brick Owl catalog.

## Parameters

- **key** (string) *required* — Brick Owl API key.
- **type** (string) — Optional item type filter.
- **brand** (string) — Optional brand filter.

## Request Body

```
null
```
