# GET /inventory/list

List inventory lots

Retrieve a list of store inventory lots with details.

## Parameters

- **key** (string) *required* — Brick Owl API key.
- **type** (string) — Optional item type filter.
- **active_only** (integer) — Include only items that are for sale.

```
null
```
