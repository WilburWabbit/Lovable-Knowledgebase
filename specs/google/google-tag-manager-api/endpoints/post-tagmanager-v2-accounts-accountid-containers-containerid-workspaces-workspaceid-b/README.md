# POST /tagmanager/v2/accounts/{accountId}/containers/{containerId}/workspaces/{workspaceId}/bulk_update

Applies multiple entity changes to a workspace in one call.

- **workspaceId** (string) *required* — Workspace ID.

```
{"changes": []}
```
