# POST /ad_campaign/{campaign_id}/update_ad_rate_strategy

Update Ad Rate Strategy

Updates the ad rate strategy for a rules-based CPS campaign.

## Parameters

- **campaign_id** (string) *required* — Unique campaign ID.

## Request Body

```
{"adRateStrategy": "FIXED", "bidPercentage": "6.0"}
```

## Response Example

```
{}
```
