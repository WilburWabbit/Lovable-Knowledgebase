# GET /ad_campaign/{campaign_id}/ad/{ad_id}

Get Ad

Retrieves a specific ad from a campaign.

## Parameters

- **ad_id** (string) *required* — Unique ad ID.
- **campaign_id** (string) *required* — Unique campaign ID.

## Request Body

```
null
```

## Response Example

```
{"adId": "111", "listingId": "222", "adStatus": "ACTIVE"}
```
