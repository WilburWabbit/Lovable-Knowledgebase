# POST /ad_campaign/{campaign_id}/update_campaign_identification

Update Campaign Identification

Updates campaign name, start date, and end date.

## Parameters

- **campaign_id** (string) *required* — Unique campaign ID.

## Request Body

```
{"campaignName": "Updated Name", "startDate": "2023-04-01T00:00:00Z", "endDate": "2023-05-01T00:00:00Z"}
```

## Response Example

```
{}
```
