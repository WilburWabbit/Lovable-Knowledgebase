# DELETE /ad_campaign/{campaign_id}/ad/{ad_id}

Delete Ad

Removes a specific ad from a campaign (CPS only).

## Parameters

- **ad_id** (string) *required* — Unique ad ID.
- **campaign_id** (string) *required* — Unique campaign ID.

## Request Body

```
null
```
