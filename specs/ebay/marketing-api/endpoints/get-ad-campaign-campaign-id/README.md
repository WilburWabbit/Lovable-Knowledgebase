# GET /ad_campaign/{campaign_id}

Get Campaign

Retrieves the details of a single campaign by ID.

## Parameters

- **campaign_id** (string) *required* — Unique campaign ID.

## Request Body

```
null
```

## Response Example

```
{"campaignId": "12345", "campaignName": "Spring Sale", "campaignStatus": "RUNNING"}
```
