# POST /ad_campaign/{campaign_id}/ad/{ad_id}/update_bid

Update Bid

Updates the bid percentage (ad rate) for a specific ad (CPS only).

## Parameters

- **ad_id** (string) *required* — Unique ad ID.
- **campaign_id** (string) *required* — Unique campaign ID.

## Request Body

```
{"bidPercentage": "7.5"}
```

## Response Example

```
{}
```
