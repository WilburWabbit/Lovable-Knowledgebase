# POST /ad_campaign/{campaign_id}/ad

Create Ad By Listing Id

Adds a listing to an existing campaign by listing ID or ad group ID.

## Parameters

- **campaign_id** (string) *required* — Unique campaign ID.

## Request Body

```
{"listingId": "123456789", "bidPercentage": "5.0"}
```

## Response Example

```
{}
```
