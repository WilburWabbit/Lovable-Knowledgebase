# GET /item/get_items_by_item_group

Retrieve individual items in an item group

This method retrieves the details of the individual items in an item group (e.g., variations of color/size).

## Parameters

- **item_group_id** (string) *required* — Identifier of the item group to return.

## Request Body

```
null
```

## Response Example

```
{ "items": [], "commonDescriptions": [] }
```
