# POST /task

createTask

This method creates an upload task or a download task without filter criteria.

## Parameters

- **X-EBAY-C-MARKETPLACE-ID** (string) — The ID of the eBay marketplace where the item is hosted.

## Request Body

```
{ "feedType": "LMS_ORDER_ACK", "schemaVersion": "1.0" }
```

## Response Example

```
{}
```
