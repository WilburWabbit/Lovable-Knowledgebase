# GET /fulfillment_policy

Get Fulfillment Policies

This method retrieves all the fulfillment policies configured for the specified marketplace.

## Parameters

- **marketplace_id** (string) *required* — eBay marketplace ID.

## Request Body

```
null
```

## Response Example

```
{"fulfillmentPolicies": [], "total": 0}
```
