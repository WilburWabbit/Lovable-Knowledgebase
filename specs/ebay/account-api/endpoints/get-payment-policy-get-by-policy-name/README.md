# GET /payment_policy/get_by_policy_name

Get Payment Policy By Name

This method retrieves details of a payment policy by name.

## Parameters

- **marketplace_id** (string) *required* — eBay marketplace ID.
- **name** (string) *required* — Seller-defined name.

## Request Body

```
null
```

## Response Example

```
{"paymentPolicyId": "string", "name": "string"}
```
