# POST /fulfillment_policy/

Create Fulfillment Policy

This method creates a new fulfillment policy.

## Parameters

_None_

## Request Body

```
{"name": "string", "marketplaceId": "string", "categoryTypes": [{"name": "string"}]}
```

## Response Example

```
{"fulfillmentPolicyId": "string", "warnings": []}
```
