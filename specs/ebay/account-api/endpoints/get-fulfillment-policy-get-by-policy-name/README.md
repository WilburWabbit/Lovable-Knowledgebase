# GET /fulfillment_policy/get_by_policy_name

Get Fulfillment Policy By Name

This method retrieves the details for a specific fulfillment policy by name.

## Parameters

- **marketplace_id** (string) *required* — eBay marketplace ID.
- **name** (string) *required* — Seller-defined name of the policy.

## Request Body

```
null
```

## Response Example

```
{"fulfillmentPolicyId": "string", "name": "string"}
```
