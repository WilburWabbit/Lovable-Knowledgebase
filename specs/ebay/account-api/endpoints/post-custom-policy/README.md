# POST /custom_policy/

Create Custom Policy

This method creates a new custom policy in which a seller specifies their terms for complying with local governmental regulations.

## Parameters

- **X-EBAY-C-MARKETPLACE-ID** (string) *required* — This header parameter specifies the eBay marketplace for the custom policy.

## Request Body

```
{"description": "string", "label": "string", "name": "string", "policyType": "string"}
```

## Response Example

```
{}
```
