# GET /fulfillment_policy/{fulfillmentPolicyId}

Get Fulfillment Policy

This method retrieves the complete details of a fulfillment policy.

## Parameters

- **fulfillmentPolicyId** (string) *required* — ID of the fulfillment policy.

## Request Body

```
null
```

## Response Example

```
{"fulfillmentPolicyId": "string", "name": "string"}
```
