# PUT /fulfillment_policy/{fulfillmentPolicyId}

Update Fulfillment Policy

This method updates an existing fulfillment policy.

## Parameters

- **fulfillmentPolicyId** (string) *required* — ID of the fulfillment policy.

## Request Body

```
{"name": "string", "marketplaceId": "string"}
```

## Response Example

```
{"fulfillmentPolicyId": "string"}
```
