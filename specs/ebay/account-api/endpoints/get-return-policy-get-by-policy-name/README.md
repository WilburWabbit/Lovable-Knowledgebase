# GET /return_policy/get_by_policy_name

Get Return Policy By Name

Retrieves return policy by name.

## Parameters

- **marketplace_id** (string) *required* — Marketplace ID.
- **name** (string) *required* — Policy name.

## Request Body

```
null
```

## Response Example

```
{"returnPolicyId": "string", "name": "string"}
```
